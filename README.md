# 📝 Lista de Tarefas

Uma aplicação web simples para **organizar e acompanhar as tarefas do dia a dia**.

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web: **HTML, CSS e JavaScript**, com foco em praticar conceitos de estruturação, estilização e interatividade.

## ⚙️ Instalação

Como este projeto utiliza apenas **HTML, CSS e JavaScript**, não é necessário instalar dependências ou utilizar `npm` para executá-lo.

### 1. Clone o repositório

No terminal, execute:

```bash
git clone https://github.com/SEU-USUARIO/lista-de-tarefas.git
```

Substitua `SEU-USUARIO` pelo seu nome de usuário do GitHub.

### 2. Entre na pasta do projeto

```bash
cd lista-de-tarefas
```

### 3. Execute o projeto

Abra o arquivo `index.html` diretamente no navegador.

Você também pode utilizar uma extensão como **Live Server** no Visual Studio Code para executar o projeto durante o desenvolvimento.

## 💻 Como usar

1. Abra a aplicação no navegador.
2. Digite uma nova tarefa.
3. Adicione a tarefa à lista.
4. Marque as tarefas concluídas conforme forem realizadas.
5. Organize suas atividades do dia a dia de acordo com suas necessidades.

## 🤝 Contribuição

Contribuições são bem-vindas!

Se você quiser contribuir com o projeto:

1. Faça um **fork** deste repositório.
2. Crie uma nova branch:

```bash
git checkout -b minha-contribuicao
```

3. Faça suas alterações.
4. Adicione e registre as alterações:

```bash
git add .
git commit -m "feat: adiciona nova funcionalidade"
```

5. Envie sua branch para o GitHub:

```bash
git push origin minha-contribuicao
```

6. Abra um **Pull Request** explicando suas alterações.
